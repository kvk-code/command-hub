## 2. Conflicts, Contradictions, and Ambiguities

- **The Conflict:** `morning-brief/SKILL.md` uses a base filename (`todos-{DATE}.md`), while its references suggest timestamped fallbacks if the file exists. However, `check-in/SKILL.md` expects a fixed base filename.
- **Impact:** The check-in skill may fail to locate the active to-do file if a timestamped version was created, leading to broken workflows.

### B. Email Delivery Behavior

- **Ambiguity:** It is unclear if the system is designed to override environment variables based on specific user requests.

### C. Notion Fallback Contradiction
- **The Conflict:** `CONNECTORS.md` prescribes falling back to meeting invite descriptions if Notion is missing. `morning-brief/SKILL.md` instructs the system to skip silently.
- **Ambiguity:** This leads to inconsistent behavior across environments without Notion integration.

### D. Version Drift
- **Observation:** `plugin.json` is at version `0.3.0`, while skill metadata is at `0.4.0`. This indicates a lack of synchronization during updates.

## 3. Potential Edge Cases and Risks

- **Downstream File Discovery:** As noted, inconsistent to-do file naming is the most significant operational risk.
- **Filter Rigor:** Instructions to skip "bot noise" are underspecified, leaving filtering logic up to interpretation and potentially missing important automated alerts.
- **State Brittleness:** Reliance on a shared `last-run.txt` for lookback logic makes the system sensitive to file corruption or unexpected overwrites.

---

## 4. Suggested Fixes

1. **Standardize File Naming:** Enforce a single naming convention or implement a robust file discovery mechanism that allows the check-in skill to find the latest version.
2. **Reconcile Notion Behavior:** Choose a single fallback strategy (silent skip or description summary) and document it consistently.
3. **Sync Versions:** Establish a pre-commit or release check to ensure version numbers across the manifest and skill files remain in sync.
4. **Clarify NLP Email Requests:** Explicitly define how natural language requests for email delivery interact with global environment variables.
